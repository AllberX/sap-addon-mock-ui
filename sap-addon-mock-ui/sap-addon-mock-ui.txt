SAP B1 Add-On UI Mock – Cadastro de Aplicações
Este projeto simula uma interface de Add-on para SAP Business One, permitindo o cadastro fictício de aplicações internas.  


/addon-sap-b1
│
├── favicon.ico                    # Seu ícone personalizado
├── index.html                    # Página principal (cadastro + lista)
├── login.html                    # Tela de login (separada)
├── style.css                    # Estilos customizados (separado do HTML)
├── script.js                    # JavaScript principal (separado do HTML)
├── README.md                    # Documentação do projeto
├── LICENSE                      # Licença do projeto (ex: MIT)
└── assets/                      # Pasta para imagens, ícones, gifs etc
    └── loading.gif

-----------


Funcionalidades

- Formulário com campos: Código, Descrição, Tipo e Status (ativo/inativo)  
- Validações básicas nos campos obrigatórios  
- Simulação de salvamento usando `localStorage` do navegador  
- Listagem das aplicações cadastradas em tabela dinâmica  
- Botões para salvar, limpar formulário e simular saída 
 
---

Tecnologias usadas

- HTML5  
- CSS3 (com Bootstrap 5 para estilo rápido e responsivo)  
- JavaScript (vanilla) para lógica e manipulação do DOM  
- LocalStorage para persistência simulada de dados  

---

Como usar

1. Clone este repositório  
2. Abra o arquivo `index.html` em seu navegador preferido  
3. Preencha o formulário e clique em "Salvar" para adicionar uma aplicação  
4. As aplicações cadastradas aparecem na tabela abaixo do formulário  
5. Use o botão "Limpar" para limpar o formulário  
6. O botão "Sair" simula o fechamento da tela (pode ser personalizado)
